# Gameplay reference captures

The screenshot and original MP4 in this directory were captured by a project
maintainer from the Brazilian retail release. They show a pass through the
top-level main-menu entries, where Career does not appear. The final Brazilian
game does not include the Career mode described in the instruction manual.

The animated GIF is a 480 × 360, 6 fps, 64-color derivative of the MP4 for
inline playback in the project README. It omits audio. These files contain
third-party gameplay imagery and are not covered by the repository's MIT
license.
