Update `notes/hypotheses.md` with: $ARGUMENTS

- Change the status to one of: `open`, `supported`, `weakened`, `confirmed`,
  `rejected`.
- Add the evidence reference (journal entry date).
- A new hypothesis gets the next free ID (H5, H6...) with a test method.
- Never mark `confirmed` or `rejected` without reproducible evidence.
- Update the hypotheses summary in `CLAUDE.md` if it changed.
